Medical Store Database Analysis
Project Overview
This project involves designing a robust database system for a medical store using MySQL. The database captures data related to inventory, sales, suppliers, and transactions. Furthermore, SQL queries were executed to extract strategic business insights from the data, enabling better decision-making.
Tools and Technologies
 Database: MySQL
 Query Language: SQL
Database Schema Highlights
The database includes key entities such as:
 Medicines: Details about drugs, stock levels, and prices.
 Suppliers: Information about medicine vendors.
 Sales/Transactions: Daily sales records and billing details.
Key Insights Addressed
Some of the key business questions answered through SQL queries include:
 Total revenue generated over a specific period.
 Top-selling medicines and categories.
 Inventory levels, identifying medicines that are out of stock.
 Supplier performance and procurement analysis.
